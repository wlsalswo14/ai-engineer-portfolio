### [`loop-evolution/`](loop-evolution) — 에이전트 루프 자가 진화 및 승격 계약
2026.06 - 현재 · 1인 개발

chess_bench에서 얻은 "루프 구조에 따라 성능이 갈린다"는 결과를, **에이전트가 스스로
자기 루프를 개선하되 개선이 진짜일 때만 승격시키는** 시스템으로 확장했습니다.

- 후보가 **인과적 구조 변경을 정확히 1개만** 선언하도록 강제하고, 이미 시도된 구조의 재제출을 차단해 탐색이 제자리를 돌지 않게 설계
- 성격이 다른 기준 상대 **3종 패널 · 3쌍 matched-pair** 실행 후 중앙값 Elo 비교로 판정 → 우연한 승격 차단
- 체스 벤치마크 기준 기존 챔피언 대비 **최대 Elo +59.3** 의 점진적 격차를 입증하며 승격
- **자동화 경계 설정** — 후보 생성·평가·승격의 내부 루프는 자동화하되, 루프 구조 자체를 바꾸는 외부 루프는 사람이 판단하도록 분리. 실행 정책을 사람이 작성한 파일로 고정하고 제안·실행이 승인된 정책과 일치하는지 **해시로 검증**해 사람이 정한 경계를 시스템이 강제

**먼저 볼 것:** [`loop-evolution/README.md`](loop-evolution/README.md) · [ARCHITECTURE.md](loop-evolution/ARCHITECTURE.md) · [SEARCH-CYCLE.md](loop-evolution/SEARCH-CYCLE.md)

## 저장소 구성

세 프로젝트는 `git subtree`로 편입되어 **각자의 커밋 이력이 그대로 보존**되어 있습니다.
각 `Add '<프로젝트>/' from commit ...` 머지 커밋 아래에 해당 프로젝트의 원래 커밋들이 붙어 있습니다.

```bash
git log --oneline --graph        # 세 갈래 이력이 합쳐진 전체 그래프
```

Windows에서 클론할 때는 경로 길이 제한 때문에 아래 설정이 필요합니다.

```bash
git clone -c core.longpaths=true https://github.com/wlsalswo14/ai-engineer-portfolio.git
```
