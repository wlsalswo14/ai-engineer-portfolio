# Durable project memory

The evolutionary champion is an indivisible loop-structure plus the representative
engine produced by that structure. Engine code alone is not the evolutionary object.

The active campaign uses one lineage in which solo and collaboration are both allowed
organizations. Search moves through two local refinements, two emergent attempts, and
then counter-hypothesis search until promotion or a development-qualified family is
found. A development candidate receives two general and two emergent refinements; if
none promotes, the lineage is discarded and counter-hypothesis search resumes.

Evaluation uses three precommitted diverse anchors, common within each pair. Formal
promotion requires wins greater than losses, candidate median Elo greater than
incumbent median Elo, and zero invalid arms. Bounded early adjudication stops after two
valid pairs only when no third-pair result can change promotion or the applicable 90%
development decision.

For the R1000 campaign, the structure-design process is an independent Sol subagent at
`max`; evolved-loop calls remain Luna `high`. Model/effort changes are an operational
upgrade requested by the user and are not eligible structural hypotheses.
