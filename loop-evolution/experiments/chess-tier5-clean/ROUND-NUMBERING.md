# Official round names

The clean experiment keeps its original internal indices for safe recovery and immutable audit references. Official names
are display aliases calculated as:

```text
official round = internal clean round + 19
```

| Internal record | Official name | Meaning |
|---|---|---|
| R0 | R19 | pre-R8 comparison baseline |
| R1 | R20 | requalified R20 structure and current champion |
| R2 | R21 | current incomplete successor candidate |
| R3 | R22 | second diverse-anchor successor test |
| R4 | R23 | precommitted forensic handoff test |
| R5 | R24 | promoted postbuild independent falsification structure |
| R6 | R25 | post-mutation certificate-gate test; not promoted |

Only names change. Directories such as `r0001`, structure and package IDs, engine artifacts, Elo values, hashes, and archived
records are not renamed or rewritten.
